## ⭐ Featured engineering work

### 01 / [Richard Informatique — Interactive Web Experience](https://github.com/ridev-lab/richard-informatique)

**JavaScript · Three.js · GLSL · WebGL · GSAP · ScrollTrigger · Lenis · Vite**

An interactive, multi-page professional website designed and implemented with native JavaScript and custom GPU-powered visuals. Its scroll-driven introduction morphs between five particle-cloud scenes; the implementation keeps rendering, geometry generation and animation timelines separate.

- **3D engineering:** custom vertex/fragment shaders and GPU particle morphing (16,000 points on larger layouts, 7,500 on smaller screens).
- **Frontend architecture:** JavaScript ES modules, ScrollTrigger timelines, smooth scrolling and responsive interactions.
- **Resilience:** reduced-motion handling, a no-WebGL fallback and pre-rendered HTML content.
- **Delivery:** a Vite static build and GitHub Actions source/build validation.

## 🔍 How I approach a project

**Understand the real requirement.** A useful solution starts with the business workflow and the people who will use it.

**Separate responsibilities.** Keep external integrations, application logic and presentation organised so changes remain manageable.

**Build for deployment.** Source control, configuration separation and repeatable builds matter as much as the final interface.

**Keep improving.** I document trade-offs and add targeted validation rather than claiming unmeasured performance or test coverage.

For an example of the code-level approach, see the [Richard Informatique architecture and engineering decisions](https://github.com/ridev-lab/richard-informatique/blob/main/docs/CASE_STUDY.md).
